## 1. Общее

### 1.1. Адрес сервера

`http://localhost:3001`

### 1.2. Используемый протокол

API реализовано на WebSocket и http.

Формат возвращаемых значений `JSON`.

### 1.3. Типы запросов

WebSocket — используется для методов работы с пользователями (регистрация, логин, логаут, обновление адреса)

HTTP POST — используется для всех остальных методов (каталог, заказы, администрирование), параметры передаются в теле запроса.

## 2. Структуры данных

### 2.1. Общий формат ответа

`T` - какие-то данные. В случае успешного ответа возвращается `result = 'ok'` и поле `data` с данными.

В случае ошибки возвращается `result = 'error'` и поле `error` с кодом и текстом ошибки

```
Answer<T>: {
    result: 'ok' | 'error';
    data?: T;
    error?: {
        code: number;
        text: string;
    };
}
```

### 2.2 User

```
type User = {
  guid: string;          - GUID пользователя         
  token: string;         - токен пользователя            
}
```

### 2.3 Product

```
type Product = {
  id: number;              - ID товара
  name: string;            - название
  price: number;           - цена
  brandId: number;         - ID бренда
  genderId: number;        - ID гендера
  typeId: number;          - ID типа
  sizeIds: number[];       - массив ID размеров
  colorIds: number[];      - массив ID цветов
  stockQuantity: number;   - количество на складе
  description: string;     - описание
}
```

### 2.4 Order

```
type Order = {
  id: number;              - ID заказа
  userId: number;          - ID пользователя
  orderTime: string;       - время создания
  statusId: number;        - ID статуса
  products: {              - товары в заказе
    productId: number;
    quantity: number;
  };
}
```
