# Установка и запуск проекта, работа с БД

## 1) Установка

Перед началом убедитесь, что на вашем компьютере установлены Node.js (версия 14.x или выше) и npm (обычно идут вместе);

### 1.1) Клиентская часть

Клиентская часть использует React и находится в папке ../pantyShop/client
   
1.1.1) Откройте терминал (командную строку)

1.1.2) Перейдите в директорию клиента: cd ../pantyShop/client

1.1.3) Установите все необходимые зависимости (библиотеки), указанные в файле package.json: npm install

### 1.2) Серверная часть
   
Серверная часть работает на Node.js и находится в папке pantyShop/server

1.2.1) Откройте новый терминал (или перейдите в корень проекта).

1.2.2) Перейдите в директорию сервера: cd ../pantyShop/server

1.2.3) Установите зависимости для сервера: npm install

## 2) Запуск

Для корректной работы приложения необходимо запустить обе части одновременно (клиент и сервер).

### 2.1) Клиентская часть

Для запуска фронтенд-части:

2.1.1) Убедитесь, что вы находитесь в папке ../pantyShop/client

2.1.2) Выполните команду: npm start

2.1.3) Дождитесь сборки проекта. Обычно приложение автоматически открывается в браузере по адресу http://localhost:3001.

### 2.2) Серверная часть

Для запуска серверной части:

2.2.1) Убедитесь, что вы находитесь в папке ../pantyShop/server

2.2.2) Запустите сервер с помощью команды: node app.js

2.2.3) Если в консоли появилось сообщение "Server PANTY_SHOP running on port 3001", значит сервер успешно запущен.

## 3) Работа с базой данных

В качестве субд в проекте используется SQLite. Файл базы данных находится по пути: ../pantyShop/server/application/modules/db/pantyShop.db

Чтобы просмотреть и редактировать данные напрямую, скачайте программу для просмотра SQLite, например DB Browser (если таковая не скачана). Запускаете установленную программу и в качестве открываемой БД выбираете ../pantyShop.db. Далее, используя инструментарий приложения, возможно просматривать и изменять данные в БД.
